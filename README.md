# StudentMS — إدارة الطلاب

مشروع تعليمي باستخدام PHP وMySQL وHTML وCSS داخل الصفحات. يستخدم PDO للاستعلامات، وPHP Session لرسائل الحالة ورمز حماية النماذج.

## الوظائف

عرض الطلاب والبحث والإضافة والتعديل والحذف، مع تحقق من المدخلات ومنع تكرار البريد الإلكتروني.

## التشغيل المحلي

1. شغّل Apache وMySQL في XAMPP أو WAMP.
2. ضع المستودع داخل htdocs أو www.
3. أنشئ قاعدة بيانات باسم `student_management` من phpMyAdmin.
4. راجع ثوابت الاتصال في `adham22/db.php`، خصوصًا المنفذ: الكود يستخدم `3307`؛ عدّله إلى `3306` إذا كان خادمك يستخدمه.
5. افتح `adham22/index.php` عبر localhost. ينشئ الكود جدول students تلقائيًا داخل قاعدة البيانات الموجودة.

## الملفات

- `db.php`: الاتصال وإنشاء الجدول والتحقق من المدخلات.
- `index.php`: قائمة الطلاب.
- `search.php`: البحث.
- `add.php` و`edit.php` و`delete.php`: العمليات على الطلاب.

جميع الملفات داخل مجلد `adham22`.

## الإصلاحات البسيطة

- يبقى رمز CSRF ثابتًا طوال الجلسة، حتى لا يُبطل فتح نموذج آخر النموذج الأول.
- التحقق من التاريخ يرفض الأيام غير الموجودة مثل 30 فبراير.
- تفاصيل خطأ الاتصال تُكتب في سجل السيرفر بدل عرضها للزائر.

## الاختبار اليدوي

استخدم بيانات وهمية: أضف طالبًا، جرّب بريدًا مكررًا وتاريخًا غير صحيح، عدّل السجل، ابحث عنه، ثم جرّب الحذف وإلغاء الحذف. افتح نموذجين في تبويبين وتأكد أن كلًا منهما يعمل.

## حدود المشروع

هذا تمرين محلي، ولا يحتوي على تسجيل دخول أو صلاحيات مستخدمين. لا تستخدمه لحفظ بيانات طلاب حقيقية على موقع عام. حساب root وكلمة المرور الفارغة إعدادات تدريب محلي فقط؛ استخدم حساب قاعدة بيانات مناسبًا عند النشر.
